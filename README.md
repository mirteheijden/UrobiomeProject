# UrobiomeProject
Urine samples were collected from cancer patients treated with oncolytic adenovirus TILT-123 and analyzed using 16S rRNAseq and Shotgun Metagenomics sequencing.

First, all samples were sequenced using 16S rRNAseq, after that, part of the samples (belonging to clinical trial TILT-T563) were re-sequenced using Shotgun metagenomics. Pre-processing was one in Puhti supercomputer, CSC, Finland. Downstream processing was done in RStudio version 4.5.1
